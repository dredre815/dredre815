# Zijun (Marshall) Zhang

PhD researcher at the University of Melbourne studying the security of LLM-based systems under constrained external interaction.

I am interested in how security changes as intelligent systems move beyond isolated models: acquiring persistent state, using tools, taking consequential actions, and interacting through shared environments.

**Model boundary → Stateful agent → Multi-principal system**

My broader interests include AI/LLM security, agent systems, research engineering, quantitative research, and intelligent systems under uncertainty.
